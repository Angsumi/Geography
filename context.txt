## 2. Component Architecture & Data Flow

```
[GEography.json] + [Activity.json]
       │
       ▼ (Decoupled & Normalized via stringMatcher.js)
  [App.jsx] (State Orchestrator & View Mode Router)
       │
       ├─► [HomePage.jsx] (Default view: 3 Chapter Cards + Site Schema Flow)
       │
       ├─► [GeographyMap.jsx] (Districts & State boundary rendering)
       │
       ├─► [SectionVisualizer.jsx] (Decoupled Visualizer Router)
       │         │
       │         └─► [visualizers/*] (18 specialized SVG/CSS diagrams, fully responsive)
       │
       └─► Learning Game Suite
                 ├─► [Flashcard.jsx] (3D Card deck)
                 ├─► [MatchGame.jsx] (Drag & drop matching columns)
                 └─► [ExamineMCQ.jsx] (Quiz module with explanation popups)
```

### Data Integration & State Machine
- **`App.jsx`** acts as the central hub. It imports and aggregates all `GEography.json` files into `syllabusData` and all `Activity.json` files into `activityData`.
- **`viewMode` State (`'home'` | `'chapter'`)**:
  - `'home'`: Displays `HomePage.jsx` launcher dashboard.
  - `'chapter'`: Displays active chapter geography map, subtopic chips, section cards, and learning activities.
- **Section Matching via `stringMatcher.js`**: Strips citation marks (e.g. `[cite: 1]`), bracketed annotations (e.g. `(NH)`), and ignores capitalization/spacing. This ensures that formatting changes in syllabus JSON files never break visualizers or learning activities.
- **Curated Activity Guarantee**: All 53 sections across `INDIA`, `ASSAM`, and `NE` contain curated activities (1,100 total items: 420 Flashcards, 418 Matching Pairs, 262 MCQs).

## 3. Dynamic Chapter Color Themes & Iconography

The application implements a dynamic theme system stored in `CHAPTER_STYLES` inside `App.jsx`:

| Chapter Key | Subject Name | Theme Accent | Active Background | Custom Icon |
| :--- | :--- | :--- | :--- | :--- |
| **`INDIA`** | India Physical Geography | `#34d399` (Emerald) | `linear-gradient(135deg, rgba(16,185,129,0.25), rgba(6,182,212,0.25))` | 🇮🇳 |
| **`ASSAM`** | Assam & Wildlife | `#fb923c` (Amber) | `linear-gradient(135deg, rgba(245,158,11,0.25), rgba(249,115,22,0.25))` | `<GamusaIcon />` (Waving Flag) |
| **`NE`** | Northeast 7 Sister States | `#f472b6` (Neon Pink) | `linear-gradient(135deg, rgba(168,85,247,0.25), rgba(236,72,153,0.25))` | 🏔️ |

### `GamusaIcon.jsx` Vector Physics:
- **Structure**: White woven cotton fabric base (`#FAFAFA`), top/bottom red woven stripes (*Pori*), woven red side panels, and central Assamese Diamond Flower motif (*Phulam*).
- **Animation**: `framer-motion` S-curve wave contour with subtle continuous `y` displacement and rotation, styled with multi-stop 3D fold highlights and flutter fringes (*Anchali*).

## 6. Build & Deployment Workflow

Vite compiles code into optimized static assets in `dist/`.

To build and deploy:
```bash
npm run build      # Compiles React code into minified dist/ bundle
npm run deploy     # Runs 'gh-pages -d dist' to publish to GitHub Pages
```
