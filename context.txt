# ADRE Geography Hub – Application Context & Architectural Documentation

This document describes the design system, data format specifications, directory layout, game mechanics, and deployment workflow for the ADRE Geography Hub. It serves as a developer guide for maintaining this codebase and extending it to new subjects.

## 2. Component Architecture & Data Flow

```
[GEography.json] + [Activity.json]
       │
       ▼ (Decoupled & Normalized via stringMatcher.js)
  [App.jsx] (State Orchestrator)
       │
       ├─► [GeographyMap.jsx] (Districts & State boundary rendering)
       │
       ├─► [SectionVisualizer.jsx] (Decoupled Visualizer Router)
       │         │
       │         └─► [visualizers/*] (17 specialized SVG/CSS diagrams)
       │
       └─► Game Modes
                 ├─► [Flashcard.jsx] (3D Card deck)
                 ├─► [MatchGame.jsx] (Drag & drop matching columns)
                 └─► [ExamineMCQ.jsx] (Quiz module with explanation popups)
```

### Data Integration
- **`App.jsx`** acts as the central hub. It imports and aggregates all `GEography.json` files into a single `syllabusData` object and all `Activity.json` files into `activityData`.
- Section matching and data association are processed via **`src/utils/stringMatcher.js`**. The utility strips citation marks (e.g. `[cite: 1]`), bracketed annotations (e.g. `(NH)`), and ignores capitalization/spacing. This ensures that formatting modifications in the syllabus files do not break active visualizers or learning activities.
- If a section lacks curated activity content, it dynamically constructs fallback MCQ, Flashcard, and Matching arrays to prevent the application from crashing.

## 4. Visualizers and Map Engine

### `GeographyMap.jsx`
- Uses an HTML5 `<canvas>` element to render geographic paths dynamically, mapping coordinates into pixel boundaries.
- **Three drawing profiles:**
  1. *India Physiographic Map:* Uses `INDIAN_SUB_DISTRICTS_COMPACT.json` to draw 6 major zones.
  2. *Assam Districts Map:* Filters the same dataset for features where `is_assam === 1`.
  3. *Northeast States Map:* Uses `NORTHEAST_STATES_ONLY.json` to draw boundaries for the 7 sister states.
- Hover detection is calculated using squared Euclidean distance threshold checks against feature centroids.

### `SectionVisualizer.jsx`
Maps section names (via robust normalization matching) to 17 customized visual components located in `src/components/visualizers/`:
- `RiverFlowVisual` / `TributariesBankVisual` / `BrahmaputraValleyVisual`: Generates animated canvas and SVG flow paths for river systems.
- `BiosphereReservesVisual`: Generates concentric circles representing Core, Buffer, and Transition zones.
- `StateProfileVisual`: Renders state cards containing local administrative data and state symbols.
- `GeneralStructureVisual` / `SoilProfileVisual` / `PlateauGridVisual`: Renders layered, stylized CSS cards mapping physical geology structures.
- `TransportVisual`: Draws detailed interactive SVG route networks (railways, highways, waterways) extracted from KML files.

## 5. Gamification Mechanics

- **Progress tracking:** Score states and XP are updated instantly.
- **Streak calculation:** Users gain a daily streak. If the gap between the last activity completion timestamp and the current time is between 24 and 48 hours, the streak increases. If it exceeds 48 hours, the streak resets to 1.
- **Sound Effects:** `useSound.js` synthesizes sounds directly using the browser's native Web Audio API oscillators, avoiding the need for external `.mp3` dependencies:
  - *Correct:* Dual triangle oscillators sounding at `523.25Hz` (C5) and `659.25Hz` (E5).
  - *Wrong:* Low sawtooth wave dropping from `180Hz` to `110Hz`.
  - *Flip:* Low-frequency sine wave click at `80Hz`.

Vite compiles code into optimized static assets. To deploy:
```bash
npm run build         # Compiles index.html, JS, and CSS chunks into dist/
npx gh-pages -d dist  # Pushes compiled bundle to gh-pages branch on GitHub
```
